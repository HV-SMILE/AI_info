# ԱԲ Հոսքի Տեղեկություններ

## Ֆայլերի կառուցվածքը
- `index.html` — գլխավոր էջ (ֆոն, 3 դասարանի կոճակներ, AI չաթ, 2 ռեսուրսի կոճակ)
- `Class10.html`, `Class11.html`, `Class12.html` — դասարանների էջեր
- `style.css` — ընդհանուր ոճաձևավորումը
- `stars.js` — աստղային ֆոնի անիմացիան
- `chat.js` — AI չաթի տրամաբանությունը (միանում է ուղիղ բրաուզերից)

## AI չաթն արդեն աշխատում է՝ անվճար, առանց key-ի

Կայքն օգտագործում է **Puter.js** գրադարանը (անվճար, բաց կոդով, https://puter.com),
որը թույլ է տալիս ուղիղ բրաուզերից խոսել Claude-ի հետ՝ առանց API key-ի և
առանց սերվերի։ Սա արդեն միացված է `index.html`-ում.

    <script src="https://js.puter.com/v2/"></script>

**Ինչպես է դա անվճար?** Puter-ն օգտագործում է այսպես կոչված «User-Pays» մոդելը.
յուրաքանչյուր այցելու իր օգտագործումը ծածկում է իր անվճար Puter հաշվի
միջոցով (հիմնականում ինքնաշխատ, ֆոնային)։ Դու՝ որպես կայքի հեղինակ,
ոչինչ չես վճարում, անկախ նրանից քանի հոգի օգտագործի չաթը։

## Ինչպես բացել կայքը
Պարզապես կրկնակի սեղմիր `index.html`-ի վրա, կամ վերբեռնիր բոլոր ֆայլերը
ցանկացած hosting-ի (օր. GitHub Pages, Netlify)։ AI չաթը կաշխատի ուղղակիորեն,
առանց լրացուցիչ կարգավորումների։

## Փոփոխություններ, որոնք հեշտությամբ կարող ես անել
- Դասարանների էջերում (`Class10.html` և այլն) փոխարինիր
  «Շուտով նյութերը կլրացվեն» տեքստը իրական նյութերով
- `style.css`-ում `--teal`, `--gold`, `--violet` փոփոխականները փոխելով՝
  կփոխես գույների ողջ սխեման
- `chat.js`-ում `SYSTEM_PROMPT` փոփոխականը կարող ես հարմարեցնել, որպեսզի
  AI-ն ավելի կոնկրետ պատասխանի ձեր առարկայի շուրջ
- `chat.js`-ում `model: 'claude-sonnet-4-6'`-ը կարող ես փոխել այլ մոդելի
  (ցանկը՝ https://developer.puter.com/ai/models/)
